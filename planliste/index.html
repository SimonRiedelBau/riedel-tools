Planliste

Alle Pläne eines Projekts an einem Ort: Dateien hineinziehen – Plan-Nr., Index und Planstand werden aus dem Dateinamen erkannt, nach Planart und Bereich einsortiert, und ein neuer Index überschreibt den alten automatisch.

Pläne hier hineinziehen

PDF, DWG, DXF, IFC … einzeln, mehrere oder ganze Ordner. Max. 50 MB je Datei.

Erkannte Dateinamen: Plancodierung BFS (BFS_88160_B_T_5_BP_U1_2233_01 → Index 01), Albus (BP041-0-V_Bew._Gründung → Index 0, Vorabzug; …-0-F_… = Freigabe), Planstand mit Index (26-24_OST_AH_V00 → Vorabzug, Index 00) sowie …_Index_b, …_Idx03 oder …_02 am Ende. „Vorabzug“, „Freigabe“, „freigegeben“ oder „zur Ausführung“ im Dateinamen bzw. im Planstempel setzen den Planstand. Ein Plan mit höherem Index ersetzt den vorhandenen (die alte Datei wird gelöscht, der alte Index bleibt im Verlauf). Bei gleichem Index ersetzt eine Freigabe den Vorabzug; ein Vorabzug ersetzt nie eine Freigabe.
