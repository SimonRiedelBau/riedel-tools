# Archiv

Tools, die zurzeit nicht genutzt werden. Ordner mit `_` am Anfang veröffentlicht GitHub Pages (Jekyll) nicht,
die Tools sind also nicht mehr online erreichbar, der Code bleibt aber hier erhalten.

Zum Reaktivieren den Ordner wieder ins Hauptverzeichnis verschieben (z. B. `git mv _archiv/lv-manager lv-manager`)
und auf der Startseite `index.html` verlinken.

- `lv-manager/` – Verwaltung von Leistungsverzeichnissen, archiviert im September 2026. Der Geräte-Sync lief über ein
  selbst eingetragenes Supabase-Projekt (Tabelle `lv_items`); vor einer Reaktivierung auf ein festes Projekt mit
  Freigabeliste umstellen, wie bei Stahllisten und Doka-Mietrechnungen.
